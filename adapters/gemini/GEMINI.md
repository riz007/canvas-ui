# canvas-ui

This extension adds a UI design workflow. When a task is to design, redesign, explore directions for, recreate, or review a user interface (website, app, dashboard, component), first read `SKILL.md` in this extension's folder (`{{SKILL_DIR}}/SKILL.md`) and follow it. Its relative links and `<skill>` placeholders refer to `{{SKILL_DIR}}`.

Skip it for pure business logic, API work, refactors without visual change, and fully specified micro-edits ("make the save button green").
